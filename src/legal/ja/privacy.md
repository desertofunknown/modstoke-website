# プライバシーポリシー

Modstokeが何を収集し、なぜ収集し、どのくらいの期間保管し、それについて何を依頼できるかを説明します。

Effective 12 November 2026

## 運営者と本ポリシーの対象 {#scope}

Modstokeは、501(c)(3)の非営利団体であり、ミズーリ州ファーミントンに拠点を置くOpenACAI Inc(以下「OpenACAI」「当社」といいます)が運営しています。本ポリシーは、modstoke.com、お客様のModstokeアカウントと panel.modstoke.com のホスティングパネル、当社がホストするゲームサーバー、当社のMODとツール、および本サイトを通じて行われる寄付を対象とします。

当社のDiscordアプリであるSentinelとRadioには、[Discordアプリのプライバシーページ](/apps/privacy/)が適用されます。OpenACAIのその他のサービスには、[独自のポリシー](https://openacai.com/privacy-policy/)があります。

要点は次のとおりです。

- アカウントとサーバーを運営し、安全に保つために必要なものだけを収集します。
- 個人情報を販売せず、広告を表示せず、お客様のデータをAIモデルの学習に使用しません。
- お客様の情報のコピーを求めること、またはその訂正や削除を求めることができます。

## サイトの閲覧 {#site}

アカウントがなくても、modstoke.comを閲覧し、当社のMODとツールをダウンロードできます。本サイトは、広告用や追跡用のCookieを設定しません。

他のウェブサイトと同様に、当社のサイトもお客様のIPアドレス、ブラウザの詳細、要求されたページを受け取ります。Cloudflareは、当社のサイトの配信と攻撃の遮断のために前面に置かれているため、そのトラフィックも確認でき、お客様を特定しない合計の訪問数を当社に提供します。サービスの運営と保護のため、サーバーログを保管します。

## お客様のアカウント {#account}

アカウントを作成またはサインインする際、当社は次のものを保管します。

- ユーザー名とメールアドレス、およびパスワードを設定した場合はそのハッシュ
- **Discord**:Discordでサインインした場合、DiscordのIDとDiscordアカウントのメールアドレス
- **Steam**:Steamを連携した場合、SteamIDと、そのアカウントがSons of the Forestを所有しているかどうか。これは、連携時とその後ときどき、Steamに照会して確認します。サーバーのオーナーとスタッフの権限はSteamIDによります
- **Nexus Mods**:Nexus Modsを連携した場合、Nexus名、アバター、Premiumかどうか、およびNexusが当社に渡すアクセストークン。トークンは暗号化して保管します
- サーバーに申し込む際やヘルプを求める際にお客様が当社に伝えたこと
- テーマやレイアウトなどのデスクトップの設定。端末間で引き継がれるようにするためです

### サインイン記録 {#records}

セキュリティのため、および適法な要請に応えられるように、パネルおよびSFTPでのすべてのサインアップ、サインイン、サインイン失敗、サインアウトを、次の情報とともに記録します。

- 時刻と使用された方法
- お客様のIPアドレス、それが解決されるネットワーク名、およびCloudflareがそれについて報告する国
- お客様のブラウザ、オペレーティングシステム、およびブラウザを区別するためにCookieに保管するランダムなID

これらの記録は365日間保管します。開くことができるのは当社の上級管理者のみであり、開くたびにそれも記録されます。法律によりアカウントの記録の保全が求められる場合は、それが終わるまで保管します。

## ホストされたサーバー {#servers}

お客様がレンタルする、またはトライアルで利用するサーバーについて、当社は次のものを保管します。

- サーバー上のすべて:ゲームのファイル、ワールド、MOD、設定、およびお客様がアップロードしたもの
- プランに定められた期間のバックアップ、および削除したファイル(ゴミ箱に7日間残ります)
- サーバーの状況:CPU、メモリ、ディスク、ネットワークの使用状況、プレイヤー数、インストールされているMOD。10分ごとに記録し、30日間保管します
- コンソールログ、イベント、クラッシュレポート。何が問題だったかをお客様と当社が確認できるようにするためです
- アップロードとMODフォルダのウイルススキャン結果:ファイルのパス、サイズ、フィンガープリント、判定
- お客様のスタッフの誰が何をしたか(サーバーのアクティビティログ)。365日間保管します
- 現在そのサーバーのデスクトップを開いている人。サーバーの他のスタッフに表示されます

当社のスタッフは、サービスを運営するため、お客様から求められたときに支援するため、不正利用やセキュリティ上の問題を調査するため、および法律で求められる場合に、サーバーのファイル、コンソール、ログを開くことができます。

### ホストされたサーバーでプレイする人々 {#players}

当社がホストするサーバーは、そこに参加する人を記録します。誰がそこでプレイし、誰がスタッフであるかはサーバーのオーナーが決めます。当社は、オーナーのため、およびサービスを安全に保つために、次のものを保管します。

- Steam名とSteamID、および各プレイヤーが参加および退出した時刻
- チャット。30日間保管します
- プレイ中のプレイヤーのワールド内での位置。位置はライブのみで、数分以内に消えます
- モデレーション:ミュート、投獄、キック、BAN、ホワイトリスト、およびスタッフがプレイヤーについて書いたメモ
- プレイヤーがModstoke Client MODを使用している場合、そのゲームが報告する体力とインベントリ

これを見ることができるのは、そのサーバーのオーナーとスタッフ、および当社のスタッフのみです。公開サーバーリストには、サーバーの名前とプレイ中の人数が表示され、誰がプレイしているかは決して表示されません。

訪問の記録は、その終了後1年間保管されます。サーバーが削除されると、そのサーバーがプレイヤーについて保持していたすべてが一緒に削除されます。

サーバーでプレイしていて、自分について何が保持されているかを知りたい場合、またはより早く削除してほしい場合は、サーバーのオーナーに尋ねるか、当社にお尋ねください。

### Ember {#ember}

デスクトップのヘルパーであるEmberは、当社自身のマシン上で動作するモデルを使って回答します。お客様の質問と、それに付随するサーバーに関する情報は、外部のAI企業に送信されず、モデルの学習にも使用されません。

## MODとツール {#tools}

Modstoke ManagerとLoaderは、リリース情報、カタログ、ダウンロードを、modstoke.com、およびNexus Modsやsotf-mods.comのストアを利用する場合はそれらから取得します。これらのリクエストには、あらゆるダウンロードと同様に、お客様のIPアドレスが含まれます。ManagerでNexus Modsにサインインする場合、それはお客様とNexusの間のことです。

## 寄付と支払い {#payments}

お支払いはPayPalを通じて行われます。当社がお客様のカード情報や銀行情報を見ること、保管することは決してありません。寄付については、PayPalの注文IDまたはサブスクリプションID、金額、そのステータス、および支払者のPayPal IDを保管します。有料ホスティングが開始された際は、プランについても同じものを、どのプランがどのサーバーの支払いであるかとともに保管します。

## Cookieとブラウザに保管されるもの {#cookies}

パネルは、動作に必要なものだけを使用します。

- サインイン状態を保つセッションCookie、およびフォームを保護するトークン
- `modstoke_device`:2年間保管されるランダムなIDで、上記のサインイン記録でのみ使用されます
- デスクトップの設定とウィンドウのレイアウト。ブラウザのストレージに保管されます
- サーバーのデスクトップをアプリとしてインストールした場合のオフラインコピー。サインアウトすると消去されます
- 通知を有効にした場合の通知サブスクリプション。通知は、Google、Mozilla、Apple、Microsoftが運営するブラウザ自身のプッシュサービスによって配信され、暗号化されて届きます

広告用のCookieはありません。

- アカウント、サーバー、ダウンロードを提供し、不具合が生じたときに修正すること

法律が法的根拠を求める場合、当社の根拠は次のとおりです。お客様との契約の履行、安全なサービスを運営するという当社の正当な利益、当社が求める場合のお客様の同意、および当社の法的義務。

## 保管期間 {#retention}

| 内容 | 期間 |
|---|---|
| アカウント情報 | お客様がアカウントの削除を求めるまで |
| サインイン記録 | 365日 |
| サーバー使用状況のサンプル | 30日 |
| ホストされたサーバーでのチャット | 30日 |
| プレイヤーの位置 | 数分 |
| ホストされたサーバーでのプレイヤーセッション | セッション終了後1年 |
| モデレーション記録、ホワイトリスト、スタッフのメモ | サーバーのスタッフが削除するまで |
| ホストされたサーバーがプレイヤーについて保持するすべて | サーバーが削除されたときに削除 |
| サーバーのアクティビティログ | 365日 |
| バックアップ | プランにより3日、7日、または30日 |
| サーバーのゴミ箱 | 7日 |
| 終了後のサーバーのファイル | 14日、その後削除 |
| サーバー削除後のトライアルのワールド | 30日 |
| 寄付と支払いの記録 | 税務および会計の規則が求める期間 |

法的保全の対象となっているものは、その保全が終わるまで保管されます。

## 安全の確保 {#security}

すべての通信はHTTPSで行われます。各お客様のサーバーは、他のサーバーやパネルから分離された独自の領域で動作します。パスワードはハッシュ化して、連携アカウントのトークンは暗号化して保管されます。サインイン記録へのアクセスは制限され、記録されます。完全に安全なシステムはなく、情報侵害がお客様の情報に影響する場合は、お客様にお知らせします。

Modstokeは13歳未満のお子様向けではなく、当社はその情報を意図的に収集しません。13歳未満のお子様がアカウントを持っているとお考えの場合は、当社にお知らせいただければ削除します。13歳から17歳の方には、親または保護者の許可が必要です。

## 現在開発中のもの {#planned}

発表済みのものの一部は、まだ稼働していません。それらが始まるときは次のように機能し、それぞれの開始前にこのページを更新します。

- **有料プラン。** PayPalが支払いを受け付けます。「寄付と支払い」に記載した記録を保管します。
- **メール。** 現在、当社はメールを送信していません。開始する場合は、お客様のアカウントとサーバーに関することが対象であり、マーケティングではありません。

- **サーバー用のDiscordチャンネル。** オンにした場合、サーバーのお知らせ、およびブリッジした場合はチャットがDiscordに投稿されます。
- **MOD、テーマ、アプリのストア。** 何かをインストールすると、あらゆるダウンロードと同様に、その提供元にダウンロードが行われたことが伝わります。
- **大規模プランでのボイスとラジオ。** それらが開始される前に、何が記録され、何が記録されないかを正確にお伝えします。
